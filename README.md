# DSA400

**[Open the DSA400 practice sheet](https://dsa400.vercel.app/sheet)**

DSA400 is a free pattern-wise DSA practice sheet with 400 problems. Browse topics and difficulty levels, mark problems complete, and track your progress. Google sign-in lets you save your completed problems to your account; you can also explore the sheet without signing in.

This repository is an information page for the live website. It does **not** contain the website source code.
